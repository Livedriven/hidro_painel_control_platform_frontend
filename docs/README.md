# Documentação do HidroControl

[Consulte os registros de decisões arquiteturais (ADRs)](adr/README.md) para entender a implementação atual, as diferenças em relação ao diagrama UML e as propostas de organização da aplicação.

Os ADRs foram registrados em **2026-10-15** e estão com status **Proposto**. A existência de código ou de um diagrama não foi considerada evidência de aceite histórico.

A estrutura atual por funcionalidade está descrita no [README do projeto](../README.md#organização-do-código) e no [ADR 0004](adr/0004-organizacao-do-codigo-por-funcionalidade.md). Os ADRs 0001–0003 preservam a análise original, com links para os arquivos realocados e notas de evolução.
